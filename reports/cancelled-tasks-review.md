# Ревизия отменённых задач

## Правило ревизии

Статус «отменена» не используется как доказательство отсутствия реализации.
Каждая карточка сопоставлена с текущим кодом, тестами, release reports и
physical ECDIS register. Code-side implementation и физическое подтверждение
разделены.

- **#2** — operation-only защита для NAVAREA V 449/26 не допускает ложные
  anchorage Areas.

  сериализует уникальные boundary vertices. Старое физическое предупреждение
  требует повторной проверки на новом EXE, но это не основание для новой
  parser-реализации.
- **#4** — regression fixtures и проверки RC1/Area уже присутствуют; физическое
  evidence duplicate-points ведётся отдельно через #77.
- **#5, #6, #7** — operation-first/offshore semantics реализованы; координаты
  сохраняются без выдумывания Area, Line или Circle.
- **#45** — NAVAREA V 522/26 разделяется на четыре Areas, без изменения Legacy
  serializer.
- **#47** — IV 789/2026 сравнивается по полному порядку 11 координат; V 502/26
  остаётся отдельным unresolved order-review case.
- **#57** — контекст точечных объектов покрыт merged Description work в #78.
- **#62** — demo XML приведён к единому радиусу и исправленному
  `RECOMMENDED ROUTE`; reproducible fixture и тесты согласованы.
- **#64** — текущая TOW-семантика сохраняет две конечные позиции и не создаёт
  неподтверждённую прямую Line.
- **#68** — section/parent Description flow реализован в #78; открытые
  физические вопросы не означают отсутствия code-side результата.
- **#71** — полный Modern/Legacy XML audit для IX 208/2026 выполнен в #78;
  физическое окно ECDIS не является доказательством XML truncation.

## Текущий порядок действий

1. Не восстанавливать отменённые задачи только из-за их старого статуса.
2. Для release closure использовать существующие активные/ожидающие #82–#85 и
   новую #86, не создавая параллельные дубли.
3. Отдельно принять решение по двум оставшимся code-side release gaps:
   Line diagnostics (#48/#79) и Description gate (#87).
4. После физического evidence и reviewed EXE выполнить freeze; Web, coastal,
   mobile и source adapters оставить в future backlog.
