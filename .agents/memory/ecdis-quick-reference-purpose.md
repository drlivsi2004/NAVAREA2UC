---
name: ECDIS quick reference purpose
description: The intended role and scope of the landing-page visual-language reference.
---

The ECDIS visual-language block is a compact printable instruction for the NAVAREA2UC engine, not merely a list of objects present in the current demo export.

**Why:** The user wants the infographic to be printable, laminatable, and kept beside a physical ECDIS; limiting it to demo labels hides supported engine semantics such as information/status `(i)` output and geometry safety rules.

**How to apply:** Keep the reference engine-wide, use demo visuals as evidence/examples, distinguish `(i)` information from Point/Line/Area/Circle output, and state the no-invented-geometry rules in plain language.
