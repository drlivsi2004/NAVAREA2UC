---
name: Project workstation baseline
description: Ordered compact workstation baseline intended for NAVAREA2UC development, corpus validation, and local preview work.
---

The planned project workstation is a Gigabyte BRIX N200 with 32 GB Crucial DDR4 memory and a 512 GB Kioxia NVMe drive.

**Why:** This balances low power and small size with enough memory and fast storage for NAVAREA2UC development, corpus runs, XML generation, and local web preview.

**How to apply:** After arrival, validate memory detection, NVMe health, cooling under a corpus run, the release geometry gate, and the local preview before treating the machine as the project's repeatable workstation.
